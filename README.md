# 🏎️ APEX PRO // GT3 擬真競速模擬器

**線上立即遊玩 (GitHub Pages)：** 👉 [https://raymond-luo-code.github.io/Apex-pro-racing/](https://raymond-luo-code.github.io/Apex-pro-racing/)

一款基於 **Three.js (WebGL)** 與原生 **Web Audio API** 打造的單檔無依賴 GT3 擬真賽車網頁遊戲，支援電腦鍵盤與手機觸控操作。

---

## ✨ 核心特色

- **🏁 三條多難度擬真賽道**
  - **★☆☆ 蒙札高速環道 (Monza High-Speed Ring)**：24m 寬路面、晴空正午光影與高速長直道。
  - **★★★ 富士山國際賽道 (Mount Fuji GP)**：20m 標準寬度、夕陽逆光與大落差髮夾彎重煞。
  - **★★★★★ 箱根午夜山道 (Hakone Midnight Touge)**：16.5m 緊湊山道、星空夜景與車頭遠光燈束。
- **⚙️ GT3 真實物理與街機雙模式**
  - 精準標定 **0–100 km/h 3.5 秒**、**0–300 km/h 40 秒** 動力與空氣阻力曲線。
  - 1.45G 輪胎摩擦圓、縱/橫向重心轉移、循跡煞車 (Trail Braking)、尾流效應 (Slipstream) 與 DRS/NOS。
- **🚗 高精細 `.glb / .gltf` 3D 車輛載入器與程序化 PBR 材質**
  - 內建無縫平鋪 **PBR 柏油路面**（Albedo + Normal + Roughness）與 PMREM 環境反射。
  - 支援線上範例模型切換，或**直接將本機 `.glb` 車輛模型拖曳進視窗即時換車**（自動縮放對齊 GT3 尺寸與綁定四輪轉向/滾動）。
- **📊 MoTeC 級單圈遙測分析系統**
  - 完整記錄速度、油門/煞車踏板、橫向 G 值、轉速與路線偏差，並提供賽車工程師單圈診斷報告。
- **🔊 原生 Web Audio 合成引擎**
  - 零外部音檔，即時合成引擎轉速諧波、退檔補油回火爆音、輪胎極限尖叫與路緣石震動音效。

## 🎮 操作說明

| 動作 | 電腦鍵盤 | 手機 / 平板觸控 |
| :--- | :--- | :--- |
| **油門 / 煞車** | `W` / `S` 或 `↑` / `↓` | 右側 GAS / BRAKE 踏板 |
| **左右轉向** | `A` / `D` 或 `←` / `→` | 左側 ◀ / ▶ 方向鍵或底部線性滑桿 |
| **循跡煞車 (入彎微煞)** | `Space` | TRAIL 黃色按鍵 |
| **手排升降檔 (MT)** | `E` (升檔) / `Q` (降檔) | GEAR+ / GEAR- 按鍵 |
| **NOS 氮氣增壓** | `N` | NOS 紫紅色按鍵 |
| **切換視角** | `C` | 頂部或左側 CAM 按鍵 |
| **救援回賽道中央** | `R` | 頂部選單重置 |
| **快速設定 / 車庫** | `H` / `Esc` | 右上角 ⚙️ 齒輪按鈕 |

## 📁 放入自訂 3D 車輛模型 (`assets/models/`)

1. 將 `.glb` 模型放入 `assets/models/` 資料夾（例如 `assets/models/my_gt3.glb`）。
2. 在遊戲右上角 **⚙️ → 車輛模型 / 材質** 中可輸入相對路徑 `assets/models/my_gt3.glb` 載入，或直接將 `.glb` 檔案拖入瀏覽器視窗。
